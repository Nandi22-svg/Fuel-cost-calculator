
# Python Fuel Cost Calculator

##  Project Overview

A Python-based command-line application that calculates
the estimated fuel cost of a journey based on distance,
fuel consumption, and fuel price.

This project demonstrates fundamental Python programming
concepts, mathematical calculations, input validation,
and error handling.

##  Features

- Calculate estimated fuel costs for any trip
- Enter travel distance in kilometres
- Enter fuel consumption in litres per 100 km
- Enter fuel price in South African Rand (ZAR)
- Display estimated fuel consumption in litres
- Display total estimated trip cost
- Validate positive numeric inputs
- Handle invalid inputs using exception handling
- Display results formatted to two decimal places

##  Technologies Used

- Python 3
- Visual Studio Code
- GitHub

##  Python Concepts Applied

- Variables and data types
- User input using `input()`
- Type conversion using `float()`
- Functions
- Conditional statements
- Arithmetic operations
- Exception handling (`try` and `except`)
- Formatted strings (f-strings)

## How It Works

The calculator uses the following formulas:

Fuel Needed (L) =
(Distance × Fuel Consumption) / 100

Total Fuel Cost (R) =
Fuel Needed × Fuel Price per Litre

### Example

Distance: 400 km

Fuel Consumption: 7 L/100 km

Fuel Price: R22.00/L

**Results:**
- Fuel Required: 28 litres
- Estimated Trip Cost: R616.00

##  How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in Visual Studio Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python fuel_cost_calculator.py
   ```

6. Enter the requested trip information.
7. View the calculated fuel cost.
